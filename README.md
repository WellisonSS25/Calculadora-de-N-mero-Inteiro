# Calculadora-de-N-mero-Inteiro

## Sobre o programa
Este programa em Python lê quatro números inteiros e calcula a diferença entre o produto dos dois primeiros e o produto dos dois últimos.  
O objetivo é aplicar uma fórmula matemática simples e exibir o resultado exatamente no formato solicitado pelo enunciado.

## Como funciona
- O programa lê quatro valores inteiros, um por linha.
- Calcula a diferença usando a fórmula: (A * B) - (C * D).
- Exibe o resultado com a palavra **DIFERENCA** em letras maiúsculas.
